# Week 03 - Portfolio and Responsive Page Practice

Week 03 continues UI recreation and page-building practice with a portfolio layout, an Instagram-style profile page, and a responsive digital agency landing page.

## Folder Contents

| Folder | Project | Focus |
| --- | --- | --- |
| `Day-01` | Frontend Portfolio Page | Personal portfolio sections, project cards, skills grid, and contact form |
| `Day-02` | Instagram Profile Layout | Sidebar navigation, profile header, highlights, tabs, and post grid using inline CSS |
| `Day-03` | Responsive Digital Agency Hero | Landing page with responsive image behavior and mobile media query |

## Concepts Practiced

- Portfolio structure
- Section-based page layout
- CSS variables
- Flexbox and responsive cards
- Contact form layout
- Social/profile UI recreation
- Media queries
- Responsive typography and image behavior

## How to View

Open the `index.html` file inside each day folder.

## Status

These projects are static frontend exercises and do not require a package manager or build step.

# Day 01 - Frontend Portfolio Page

This project is a personal portfolio-style webpage for a frontend engineer. It includes a fixed navigation bar, hero section, skills section, project cards, contact form, and social links.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Portfolio page markup |
| `styles.css` | Full visual styling, layout, responsive behavior, and design tokens |

## Features

- Fixed navigation header
- Hero section with name, title, and introduction
- Technical skills grid
- Project cards with icons and technology tags
- Contact form with input fields and textarea
- Social links section
- Responsive layout adjustments for smaller screens

## Concepts Practiced

- CSS custom properties
- Section-based page structure
- Flexbox cards
- Responsive layout with media queries
- Forms and labels
- Hover states
- Typography pairing with Google Fonts

## How to View

Open `index.html` in a browser.

## Notes

Some listed portfolio skills and project examples are sample content. The page is useful as a design and layout exercise and can later be updated with real project links.

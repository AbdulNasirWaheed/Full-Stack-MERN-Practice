# Day 02 - Instagram Profile Layout

This project is another Instagram-style profile page recreation. It uses a sidebar navigation, profile header, follower stats, highlights, tabs, and a responsive post grid.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Complete HTML and internal CSS for the page |

## Features

- Sticky left sidebar
- Instagram-style navigation links
- Profile picture area with gradient ring
- Username row with buttons
- Stats, bio, and related account links
- Story highlights
- Tab navigation
- Three-column post grid
- Mobile media query that hides the sidebar and centers profile content

## Concepts Practiced

- Building a full page in one HTML file
- Inline CSS organization
- Sticky positioning
- Flexbox layout
- Responsive profile sections
- Mobile-first adjustments with media queries

## How to View

Open `index.html` in a browser.

## Notes

The project uses remote placeholder images from Picsum. Some special characters may display incorrectly depending on file encoding.

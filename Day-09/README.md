# Day 01 - CSS Animation Tasks

This folder contains four small HTML/CSS exercises focused on animation, hover effects, and responsive layout.

## Files

| File | Purpose |
| --- | --- |
| `button.html` | Animated button with hover and active states |
| `boucing-ball.html` | Bouncing ball animation using CSS keyframes |
| `progress-bar.html` | Loading progress bar animation |
| `image-gallery.html` | Responsive image gallery with hover transform effects |

## Features

- Button color change on hover
- Button scale effect on hover and active press
- Infinite bouncing ball animation
- Animated loading bar
- Three-column image gallery
- Responsive gallery breakpoints for tablet and mobile
- Image hover scaling and rotation

## Concepts Practiced

- CSS transitions
- `transform: scale`
- `transform: rotate`
- `@keyframes`
- Animation timing
- CSS Grid
- Media queries
- Image sizing with `object-fit`

## How to View

Open any HTML file in a browser:

- `button.html`
- `boucing-ball.html`
- `progress-bar.html`
- `image-gallery.html`

## Notes

The bouncing ball filename is currently spelled `boucing-ball.html`, so use that exact filename when opening it.

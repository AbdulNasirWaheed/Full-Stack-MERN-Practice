# Day 01 - Explore Northern Pakistan Hero

This project is a full-screen travel hero section for "Explore Northern Pakistan." It uses a large background image, oversized headline text, and a call-to-action button.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Contains the full HTML structure and internal CSS styles |
| `pexels-photo-291732.jpg` | Local image asset available in the folder, though the page currently uses a remote Pexels image URL |

## Features

- Full viewport hero section
- Background image with cover positioning
- Large white heading text
- Call-to-action button
- Remix Icon arrow inside the button

## Concepts Practiced

- Using `background-image`
- Controlling viewport width and height
- Applying spacing with padding and margins
- Styling buttons
- Combining text and icons in a call-to-action

## How to View

Open `index.html` in a browser.

## Notes

The page loads an external Remix Icon stylesheet and a remote image URL, so those assets require internet access to appear exactly as designed.

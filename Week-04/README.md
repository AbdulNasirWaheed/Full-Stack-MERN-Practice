# Week 04 - CSS Animation and Advanced Layout

Week 04 focuses on motion, hover interactions, responsive galleries, and a larger dashboard-style layout.

## Folder Contents

| Folder | Project | Focus |
| --- | --- | --- |
| `Day-01` | Small CSS Animation Tasks | Animated button, bouncing ball, loading progress bar, and responsive image gallery |
| `Day-02` | Multimodal Content Hub | Complex dashboard layout using CSS Grid, cards, sidebar, content sections, and responsive breakpoints |

## Concepts Practiced

- CSS transitions
- Transform effects
- Keyframe animations
- Responsive image galleries
- CSS Grid layout
- Nested grid sections
- Dashboard-style UI composition
- Responsive breakpoints

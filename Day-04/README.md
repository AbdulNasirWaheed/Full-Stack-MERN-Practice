# Day 02 - Instagram Profile Recreation

This project recreates an Instagram-style profile page using HTML and CSS. It includes a fixed icon sidebar, profile information, action buttons, story highlights, tabs, and a post grid with hover overlays.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Main profile page markup |
| `style.css` | Styling for sidebar, profile header, highlights, tabs, grid, and hover states |

## Features

- Fixed vertical sidebar navigation
- Profile image and username section
- Follower, following, and post stats
- Follow, message, and add buttons
- Highlight story circles
- Tab navigation for posts, reels, tagged, and collabs
- Three-column post grid
- Hover overlay with like/comment indicators

## Concepts Practiced

- Flexbox page layout
- Fixed positioning
- Circular images
- SVG icons inside HTML
- Hover effects
- Image grids
- UI spacing and alignment

## How to View

Open `index.html` in a browser.

## Notes

The page uses remote image URLs. Some special characters in the text appear with encoding artifacts in the source, but the layout work remains clear.

# Day 02 - Multimodal Content Hub

This project is a dashboard-style content hub layout built with HTML and CSS. It includes a header, sidebar, featured content area, trending section, quick links, nested cards, social feed, promotional card, and footer.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Complete HTML and internal CSS for the dashboard layout |

## Features

- Top header with logo, navigation, search box, and avatar
- Sidebar user card, stats, and control buttons
- Featured multimedia spotlight section
- Trending list and tag group
- Quick links card
- Nested grid with news, events, blogs, and video cards
- Social feed card
- Promotional call-to-action card
- Multi-column footer
- Responsive layout changes for tablet and mobile screens

## Concepts Practiced

- CSS Grid with multiple columns and rows
- Nested grids
- Dashboard-style information architecture
- CSS variables for colors, radius, and shadows
- Responsive breakpoints
- Card-based UI composition
- Header, sidebar, main content, and footer layout

## How to View

Open `index.html` in a browser.

## Notes

This is one of the more advanced static layout exercises in the repository because it combines many independent sections into one coordinated responsive page.

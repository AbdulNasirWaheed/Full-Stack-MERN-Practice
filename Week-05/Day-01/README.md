# Responsive HTML and CSS Tasks

This repository contains three beginner-friendly responsive web design tasks made with only HTML and CSS.

## Tasks

### Task 1: Responsive Background Color

This page has a heading and paragraph. The background color changes on different screen sizes.

- Desktop screen: light blue
- Tablet screen: light green
- Mobile screen: light pink

Files:

- `task1.html`
- `task1.css`

### Task 2: Responsive Image Gallery

This page has a gallery with 8 images. The number of images in each row changes on different screen sizes.

- Desktop screen: 4 images per row
- Tablet screen: 2 images per row
- Mobile screen: 1 image per row

Files:

- `task2.html`
- `task2.css`

### Task 3: Responsive Sidebar Layout

This page has a sidebar and a main content area. The sidebar changes position on smaller screens.

- Desktop screen: sidebar on the left side
- Mobile screen: sidebar on the top

Files:

- `task3.html`
- `task3.css`

## Concepts Used

- HTML
- CSS
- Media queries
- CSS Grid
- Flexbox
- Responsive images
- `min-width`
- `max-width`

## How to View

Open any HTML file in a browser:

- `task1.html`
- `task2.html`
- `task3.html`

Resize the browser window to see the responsive design changes.

# Day 01 - Responsive HTML and CSS Tasks

This folder contains three beginner-friendly responsive web design tasks built with HTML and CSS.

## Task Overview

| Task | Files | Focus |
| --- | --- | --- |
| Task 1 | `task1.html`, `task1.css` | Background color changes across mobile, tablet, and desktop breakpoints |
| Task 2 | `task2.html`, `task2.css` | Responsive image gallery using CSS Grid |
| Task 3 | `task3.html`, `task3.css` | Sidebar and main content layout using Flexbox |

## Task Details

### Task 1 - Responsive Background Color

This page displays a heading and paragraph while changing the background color by screen size.

- Mobile: light pink
- Tablet: light green
- Desktop: light blue

### Task 2 - Responsive Image Gallery

This page displays an eight-image gallery that changes its column count based on screen width.

- Mobile: 1 image per row
- Tablet: 2 images per row
- Desktop: 4 images per row

### Task 3 - Responsive Sidebar Layout

This page contains a sidebar and a main content area. The sidebar moves based on available screen width.

- Mobile: sidebar appears above the main content
- Tablet and desktop: sidebar appears on the left side

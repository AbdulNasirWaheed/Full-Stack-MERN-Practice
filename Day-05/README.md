# Day 03 - Digital Agency Hero Page

This project is a landing page hero inspired by a digital agency website. It combines fixed navigation, large serif typography, layered images, and a simple call-to-action.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Main page structure |
| `style.css` | Layout, typography, image placement, and button styling |

## Features

- Fixed top navigation
- Brand logo and navigation links
- Contact button with arrow icon
- Full-screen hero section
- Three positioned image blocks
- Centered headline with underline accent
- "Find out more" call-to-action

## Concepts Practiced

- Fixed header layout
- Absolute positioning
- Layering with `z-index`
- External Google Fonts
- Image cropping with `object-fit`
- Hover states
- Decorative text underline using a pseudo-element

## How to View

Open `index.html` in a browser.

## Notes

The project depends on Google Fonts and remote Pexels images. Internet access is required for those assets to load.

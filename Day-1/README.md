# Day 1 - First HTML Page

This folder contains the first HTML exercise: a simple page that displays "Hello World" in the browser.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Basic HTML document with a short text output |
| `*.JPG` screenshots | Visual notes showing live server setup, folder access, and Git workflow steps |

## Concepts Practiced

- Creating an HTML file
- Understanding the basic HTML page structure
- Opening a web page in the browser
- Using live server during development
- Capturing progress with screenshots
- Practicing early Git workflow steps

## How to View

Open `index.html` in a browser.

## Notes

This is intentionally minimal. The goal of the exercise is to confirm the development setup and understand how an HTML file becomes a visible web page.

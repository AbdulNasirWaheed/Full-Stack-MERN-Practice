Over the past 1.5 months, I have been consistently building my foundation in full-stack web development through hands-on practice.

This phase has been focused on strengthening the fundamentals that every strong MERN developer needs: clean HTML structure, CSS styling, responsive layouts, Flexbox, CSS Grid, UI recreation, image-based sections, profile pages, portfolio layouts, and small animation exercises.

Some of the work I completed includes:

- Building my first HTML pages and understanding document structure
- Practicing headings, paragraphs, lists, links, images, and semantic page layout
- Creating hero sections and landing page designs
- Recreating social media style profile pages
- Designing a personal portfolio interface
- Working with responsive image galleries
- Practicing CSS transitions, hover effects, and keyframe animations
- Building dashboard-style layouts with CSS Grid and nested sections
- Using media queries to adapt pages across desktop, tablet, and mobile screens

What I value most about this progress is the consistency. Each task helped me understand not just how to write code, but how layout, spacing, responsiveness, and visual hierarchy come together to create better user experiences.

This is still the foundation stage, but it is an important one. My next goal is to keep moving deeper into JavaScript, React, Node.js, Express, MongoDB, and real full-stack MERN projects.

Excited to keep learning, building, and improving one project at a time.

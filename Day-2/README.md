# Day 2 - Basic HTML Elements

This exercise expands beyond the first page by adding common HTML content elements.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Demonstrates headings, paragraph text, a horizontal rule, a line break, and list elements |

## Features

- Six heading levels from `h1` to `h6`
- Paragraph content
- Line break usage with `br`
- Horizontal divider with `hr`
- Ordered list
- Unordered list

## Concepts Practiced

- Structuring visible page content
- Understanding heading hierarchy
- Separating content with semantic HTML elements
- Creating ordered and unordered lists

## How to View

Open `index.html` in a browser.

## Status

This is a static HTML-only exercise with no external dependencies.

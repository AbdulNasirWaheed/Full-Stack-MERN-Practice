# Day 03 - Responsive Digital Agency Hero

This project revisits the digital agency hero page and adds responsive behavior for smaller screens.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure for the agency-style landing page |
| `style.css` | Visual design, image positioning, and responsive media query |

## Features

- Fixed navigation bar
- Brand mark and navigation links
- Layered hero images
- Centered hero headline
- Underline accent on key text
- Call-to-action link with circular arrow
- Mobile media query that hides decorative images and navigation links

## Concepts Practiced

- Reusing and refining a layout
- Absolute positioning
- Responsive simplification for mobile screens
- CSS media queries
- External fonts and remote image assets
- Hover styling

## How to View

Open `index.html` in a browser.

## Notes

This version is more responsive than the Week 02 version because it includes a mobile breakpoint for the hero images, navigation links, and headline size.

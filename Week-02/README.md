# Week 02 - CSS Layout and UI Recreation

Week 02 focuses on styling static pages with CSS and recreating common user interface patterns. The exercises include a travel hero section, an Instagram-style profile page, and a digital agency landing page.

## Folder Contents

| Folder | Project | Focus |
| --- | --- | --- |
| `Day-01` | Explore Northern Pakistan Hero | Full-screen hero section with background image and call-to-action button |
| `Day-02` | Instagram Profile Recreation | Sidebar navigation, profile header, highlights, tabs, and post grid |
| `Day-03` | Digital Agency Hero Page | Fixed navigation, image layering, hero typography, and hover effects |

## Concepts Practiced

- CSS reset basics
- Full-screen hero sections
- Background images and positioning
- External icon/font resources
- Fixed navigation
- Flexbox layout
- Image grids
- Hover interactions
- UI recreation from familiar web patterns

## How to View

Open the `index.html` file inside each day folder.

## Status

All projects in this week are static HTML/CSS exercises. No package installation is required.

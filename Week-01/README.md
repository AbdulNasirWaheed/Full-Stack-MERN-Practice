# Week 01 - HTML Foundations

Week 01 introduces the basics of creating and viewing HTML pages. The work starts with a simple "Hello World" page and then expands into common HTML elements such as headings, paragraphs, line breaks, horizontal rules, ordered lists, and unordered lists.

## Folder Contents

| Folder | Description |
| --- | --- |
| `Day-1` | First HTML page, live server screenshots, and Git workflow screenshots |
| `Day-2` | Basic HTML content structure using headings, paragraph text, and lists |

## Concepts Practiced

- Creating a basic HTML document
- Using the `DOCTYPE`, `html`, `head`, and `body` structure
- Displaying text in the browser
- Working with heading levels from `h1` to `h6`
- Creating paragraphs and line breaks
- Creating ordered and unordered lists
- Getting comfortable with the editor, live server, and Git workflow

## How to View

Open each day folder and launch the `index.html` file in a browser.

## Status

This week is a beginner foundation week and does not require any package installation or build tools.

# Full-Stack MERN Practice

This repository tracks my Skills Grid full-stack development practice. The current work focuses on web development foundations: HTML structure, CSS styling, responsive layouts, UI recreation, CSS Grid, Flexbox, and simple animations.

Although the long-term direction is MERN stack development, the files currently present in this workspace are mainly frontend foundation exercises.

## Repository Structure

| Folder | Focus |
| --- | --- |
| `Week-01` | HTML setup, first web page, headings, paragraphs, lists, and basic document structure |
| `Week-02` | Hero sections, profile page layouts, navigation, image-based landing pages, and CSS styling |
| `Week-03` | Portfolio page design, Instagram-style layout practice, and responsive landing page refinement |
| `Week-04` | CSS animations, interactive hover effects, responsive galleries, and complex grid layouts |
| `Week-05` | Responsive design tasks using media queries, CSS Grid, and Flexbox |

## How to Use

Most exercises are static HTML/CSS projects. Open the relevant `.html` file directly in a browser or through a local live server extension.

## Documentation

Each week and day folder contains its own `README.md` file describing:

- What the exercise demonstrates
- Important files
- Concepts practiced
- How to view the work
- Notes about current status

## Progress Summary

Across these exercises, the practice moves from simple HTML pages to more polished layouts with responsive behavior, image galleries, profile pages, portfolio sections, dashboards, and CSS animation effects.
